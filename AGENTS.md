# Project context

`gpu-doodle` is a pnpm workspace. It follows the layout and recipe of [gpu-time](https://github.com/arikchakma/gpu-time): a tiny sequence model trained in PyTorch, exported as int6 weights, and run in the browser through a hand-written WGSL kernel with a scalar CPU reference. Keep new files consistent with that layout and its kebab-case naming.

## Layout

- `packages/core` — the publishable `gpu-doodle` package. `preprocess.ts` (shared by browser and training), `labels.ts`, WGSL kernel, CPU reference, build, and unit tests. **Zero runtime dependencies; keep it that way.**
- `packages/training` — `torch/` for Python (uv project, Python 3.13), `data/` for the class list, the download manifest, `simplified/` (ignored ndjson prefixes) and `synth/` (ignored featurized splits), `active/` for the promoted export report and parity fixtures, `runs/` for training history (only `report.json` and `source/` snapshots are tracked, never `.pt`).
- `apps/site` — the Vite demo: a canvas, guess-while-drawing, top-5 probabilities, a twenty-second prompt mode. Plain TypeScript, no framework. The UI ships in Chinese and English (`src/i18n.ts`): it follows the system language by default, with a persisted switch and `?lang=`. Chinese shows English category names beside the Chinese ones; English shows the label alone. Category translations stay in `packages/core` (`labelZh`); a third language would put its table in the site, never in core. A light/dark/system theme switch overrides `prefers-color-scheme` through `data-theme` on `<html>`. `tests/smoke.mjs` runs under Playwright's default en-US locale, so text assertions go through `data-*` hooks. `index.html` carries static `og:*` and `twitter:card` tags in Chinese (crawlers do not run the language script); `og:url` and `og:image` are absolute `https://sorrycc.github.io/gpu-doodle/` URLs because Vite's `--base` never rewrites meta `content`. `scripts/og.mjs` renders `public/og.png`; the smoke test asserts the tag names a 1200×630 PNG that exists.

## Validation

```sh
pnpm install
pnpm data:fetch     # download 20 MB prefixes of the 100 full/simplified ndjson files, verify sha256
pnpm data:build     # filter recognized, split by key_id hash, delta-encode into data/synth/default
pnpm train -- --run <name> --epochs 20
pnpm export -- --checkpoint runs/<name>/best.pt   # int6 weights.gen.ts, export-report.json, parity fixtures; gated
pnpm test           # core unit tests (preprocess parity, CPU vs PyTorch parity, weights hash) and training checks (scan, padding, stroke-3, wire roundtrip, split)
pnpm build:core     # emits packages/core/dist: minified ESM entry with kernel and weights inlined, declarations, size.json
pnpm size:gate      # strict 50,000-byte Brotli release limit
pnpm check:package  # npm pack into a throwaway consumer, type-check the declarations, run one classification
pnpm test:browser   # headless Chrome: WebGPU vs CPU on 10,000 test sketches, vs PyTorch on 512, device recovery, backend selection
pnpm site:dev       # builds packages/core, then the Vite dev server for apps/site; the site consumes dist, never src
pnpm site:smoke     # headless Chrome: load the demo, draw a circle, require a guess list and no console errors
pnpm site:og        # regenerate apps/site/public/og.png (1200×630 link preview) after a UI change; committed, never built in CI
```

Python is always invoked through `uv`. Node 24+ runs TypeScript directly via `--experimental-strip-types`; relative imports in scripts run this way must use explicit `.ts` extensions. Scripts that import `packages/core/src` run under `tsx`.

## Rules

- Do not lower an existing release gate. The Brotli budget is 50,000 bytes; `pnpm size:gate` blocks CI.
- Geometry lives in `packages/core/src/preprocess.ts` only. Training reads prefixes of Google's `full/simplified` ndjson, which is that geometry's output, and never re-implements alignment, scaling, resampling, or RDP. `dataset.py` only filters `recognized`, splits by `key_id` hash, and delta-encodes like `toStroke3`. The parity test compares TypeScript preprocessing of `full/raw` sketches against Google's `full/simplified` output for the same `key_id`.
- The `test` split is reported, never used for model selection or threshold fitting. Select on `valid`.
- Sketches longer than 128 points are dropped at build time and counted in the synth manifest; the runtime still accepts any length.
- The ndjson prefixes are the first 20 MB of each file, not a random sample. Say so wherever a number from them is quoted.
- Export is gated. A candidate ships only if it strictly improves test top-1 with no per-class regression beyond the two-proportion tolerance and no regression in first-3-stroke accuracy. Use `--force` only deliberately; it records what it overrode.
- `packages/core/src/model/weights.gen.ts` is generated by `training/torch/export.py` and hash-verified against `packages/training/active/export-report.json` by `packages/core/test/model-parity.test.ts`. Do not hand-edit it.
- The kernel never ships as a file. `scripts/build.ts` splices constants via `shader-source.ts`, minifies with wgslender and inlines the string; `shader.ts` and `weights.gen.ts` are replaced at build time, so keep placeholder names (`ROUND_BODY`, `STATE_TYPE`) out of kernel comments.
- `packages/core/src/model/kernel.wgsl` mirrors `cpu.ts` stage for stage in the same accumulation order. It names tensor offsets and dimensions symbolically; `shader-source.ts` splices them from `weights.gen.ts` before compilation, so a model change never edits the WGSL. `pnpm test:browser` is the gate: 10,000 test sketches must give the same argmax on WebGPU and CPU, with logits within 0.001.
- `classify` stays synchronous and on the CPU. WebGPU pays off only for batches; `defineClassifier` exposes it, and `"auto"` keeps small batches on the CPU.
- `packages/core/src/model/cpu.ts` is the scalar reference. It mirrors `DoodleTagger.forward` with `reference_scan = True`; `featurize` there mirrors `Dataset.features_of`. Any change to the model or the feature layout changes both files and re-runs the export, or the parity test fails.
- Every export scores the decoded int6 weights, never the f32 checkpoint, and snapshots its sources into `exports/<artifactSha256>/source/`. Only the promoted export's snapshot is tracked; add its path to `.gitignore` as an exception when promoting.
- Every training run snapshots its source files and their hashes into `runs/<run>/source/`.
- Quick Draw data is CC BY 4.0. The site, README, and MODEL_CARD must credit Google's Quick Draw dataset.

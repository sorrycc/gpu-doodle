# Project context

`gpu-doodle` is a pnpm workspace. It follows the layout and recipe of [gpu-time](https://github.com/arikchakma/gpu-time): a tiny sequence model trained in PyTorch, exported as int6 weights, and run in the browser through a hand-written WGSL kernel with a scalar CPU reference. Keep new files consistent with that layout and its kebab-case naming.

## Layout

- `packages/core` — the publishable `gpu-doodle` package. `preprocess.ts` (shared by browser and training), `labels.ts`, WGSL kernel, CPU reference, build, and unit tests. **Zero runtime dependencies; keep it that way.**
- `packages/training` — `torch/` for Python (uv project, Python 3.13), `data/` for the class list and download manifest (npz files are ignored), `active/` for the promoted export report and parity fixtures, `runs/` for training history (only `report.json` and `source/` snapshots are tracked, never `.pt`).
- `apps/site` — the Vite demo: a canvas, guess-while-drawing, top-3 probabilities.

## Validation

```sh
pnpm install
pnpm data:fetch        # download the 30 Quick Draw sketchrnn npz files, verify sha256
pnpm test           # core unit tests (preprocess parity, decode, CPU vs PyTorch fixtures)
pnpm build:core     # emits packages/core/dist
pnpm size:gate      # strict 50,000-byte Brotli release limit
pnpm test:browser   # real WebGPU vs CPU argmax on 10,000 sketches
```

Python is always invoked through `uv`. Node 24+ runs TypeScript directly via `--experimental-strip-types`; relative imports in scripts run this way must use explicit `.ts` extensions. Scripts that import `packages/core/src` run under `tsx`.

## Rules

- Do not lower an existing release gate. The Brotli budget is 50,000 bytes; `pnpm size:gate` blocks CI.
- Geometry lives in `packages/core/src/preprocess.ts` only. Training reads the already-simplified sketchrnn npz and never re-implements alignment, scaling, resampling, or RDP. The parity test compares TypeScript preprocessing of `full/raw` sketches against Google's `full/simplified` output for the same `key_id`.
- The `test` split is reported, never used for model selection or threshold fitting. Select on `valid`.
- Export is gated. A candidate ships only if it strictly improves test top-1 with no per-class regression beyond the two-proportion tolerance and no regression in first-3-stroke accuracy. Use `--force` only deliberately; it records what it overrode.
- `packages/core/src/model/weights.gen.ts` is generated by `training/torch/export.py` and hash-verified against `packages/training/active/export-report.json`. Do not hand-edit it.
- Every training run snapshots its source files and their hashes into `runs/<run>/source/`.
- Quick Draw data is CC BY 4.0. The site, README, and MODEL_CARD must credit Google's Quick Draw dataset.
